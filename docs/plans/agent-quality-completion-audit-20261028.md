# Agent-quality completion audit

Audited on 28 October 2026 against the original Q0–Q4 body in [the implementation plan](tupies-agent-quality-20261028.md) and the [Grok follow-up](../research/grok-bot-0.77.0-followup.md). This separates delivered mechanisms from tests and from unmeasured product-quality targets. The earlier statement that every stage was implemented did not mean every acceptance measurement was complete.

## What the audit found and completed

The first implementation covered the main engine mechanisms, but the evaluation cases omitted several promised checks. The coding case had no actual command exit, the long-context case checked only one middle fact, the memory case lacked a conflicting imported note/paraphrased follow-up/provenance oracle, the large-result case lacked a stale edit, and the specialist case did not exercise a required mechanical failure. Reports lacked finite quality denominators, per-case usage and repeat variance. These gaps are now implemented in `eval/runner.mjs`, `eval/scenarios.mjs` and `test/evaluation.test.mjs`.

The audit also identified source-evidence gaps: a non-success HTTP response could satisfy a source-read predicate; child results lacked structured source references; summary source IDs/merge failures needed stricter coverage; explicit subtopic recall and provenance visibility needed finishing; and legacy third-party lane bridges needed exclusion. Current engine/context/memory tests cover the corresponding fixes. Historical already-compacted text cannot be reliably classified by guessing its meaning; that residual migration limit is explicit.

## Verification and remaining work

The upgraded evaluation tests pass 9/9. Its three-repeat scripted run passes 24/24 with known normal-task completion 18/18, false success 0/18, exact retention 15/15, source checks 12/12, unauthorized-change checks 0/15 and duplicate-effect checks 0/9. These denominators describe this finite fixture set, not population rates. Human interventions remain unmeasured. The retained report is `output/research/tupies-agent-quality-20261028/fixture-report-audited.json`; the final integrated report was regenerated against 15 matching source identities.

The added retrieval corpus passes 3/3 mechanism/arithmetic/privacy tests and records the actual finite k=4 scores: relevant IDs 41/41, precision 41/124, returned-source relevance 41/84, valid references 84/84 and one stale history candidate. Core-fact relevance recall is 21/21 versus the explicitly labeled recency comparator's 12/21. Low precision is retained; this is neither human-reviewed ground truth nor measured model use of facts.

Remaining measurement is human label review, real-model answer quality, actual stale-fact use, cost/cache/latency changes, multi-day behavior and matched teammate/Grok comparisons. New source has not been deployed by this audit. The owner should receive an honest code-complete/measurement-pending distinction rather than a claim that every qualitative target has been achieved.
