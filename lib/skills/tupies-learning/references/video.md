# Learn from video evidence

A video URL is a pointer, not proof that its speech, slides or demonstrations were read. Distinguish an available caption track, an owner-supplied timestamped transcript, authorized accessible audio and a link with no usable content.

For an uploaded VTT/SRT/plain transcript, use the reader actually offered for that file. Preserve supplied timestamps and speaker distinctions. If only text without timing exists, cite its real headings/line ranges rather than inventing video intervals. Label transcription uncertainty in names, terminology, numbers and negations.

When `study_material` is actually offered, pass an admitted supported video `url` or an existing transcript `workspacePath` using its real schema. Use native video/OCR/transcription support only when the executing Engine reports that specific capability available and the owner admits the source and processing destination. Tool presence alone does not establish that a caption track, audio or visual evidence can be read. Do not infer access from a browser login or unrelated provider connection. Do not install downloaders, call a foreign runtime, or issue ad hoc terminal commands to bypass an unavailable caption/audio adapter.

Transcripts can omit the evidence in slides, charts, code and demonstrations. Identify references such as “this number” or “as shown here” that cannot be resolved from the accessible text. Read relevant images only if an actual supported tool shows them to the current model; an image filename or caption is not visual inspection. Missing visual evidence limits the resulting knowledge and completion claim.

Apply the same role relevance, scope, conditions, exceptions and existing-note comparison as for documents. Keep an author's recommendation distinct from a measured result, and a historical platform behavior distinct from its current verified behavior. Derivative videos repeating the same underlying claim do not create multiple independent confirmations.

Save self-contained useful knowledge, with the source/channel, date when known, real locators, evidence status and unavailable-original status. Explain the finite media coverage and unresolved audio/visual gaps. Never describe a video as fully learned from its title, description, search snippet or an incomplete transcript.
