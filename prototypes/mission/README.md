# Mission — HTML-прототип

Інтерактивний прототип вкладки Mission на основі поточних стилів Tupies: Pearl, навігація, скляні елементи й наявні аватари ботів. Він використовує локальні файли з `public/` без нових залежностей.

Із кореня репозиторію запустіть:

```sh
node prototypes/mission/serve.mjs
```

Відкрийте [локальний прототип](http://127.0.0.1:4387/prototypes/mission/index.html). Сервер слухає лише `127.0.0.1` і віддає тільки файли прототипу та явно дозволені стилі й зображення. Інший порт можна задати через `MISSION_PREVIEW_PORT`.

Також можна відкрити `index.html` безпосередньо в браузері. Зберігайте папку прототипу в репозиторії, щоб відносні посилання на стилі та аватари працювали.

Для перегляду або передачі одним HTML-файлом використовуйте `mission-preview.html`: усі стилі, код, чотири аватари, брендове зображення та іконка вже вбудовані. Його можна перенести в будь-яку папку й відкрити без сервера та доступу до інтернету. Після зміни вихідних файлів перебудуйте його:

```sh
node prototypes/mission/build-preview.mjs
```

Збірка перевіряє, що посилання на локальні стилі та зображення замінені, а CSS не містить зовнішніх залежностей. Редагуйте `index.html`, `mission.css` і `mission.js`; `mission-preview.html` генерується з них та наявних стилів Tupies.

Дані демонстраційні. Зміни зберігаються лише в пам’яті відкритої сторінки та скидаються після перезавантаження. Прототип не підключений до Tupies Engine, не запускає ботів і не змінює робочі місії, чати чи облікові записи.

Перевірено синтаксис Node.js та фактичну роботу в Chrome на ширинах 1280, 834, 390 і 320 px: без горизонтального переповнення сторінки, у світлій і темній темах. Перевірені створення через форму, спільний стан питання в чаті й деталях, заперечні та гіпотетичні запити в чаті, збереження чернетки під час навігації, Pause/Resume/Stop зі збереженням 33% прогресу, наступний результат до 80% і фінальна перевірка до 100%, перегляд результату, відмова в демонстраційному погодженні та порожній пошук. Знімки: `preview-desktop.jpg`, `preview-detail.jpg`, `preview-mobile.jpg`.

Це перевірка інтерфейсного прототипу. Реальні запуски Engine, нативний застосунок і поведінка моделей не входили до неї.

Production source now has the separate Engine-backed A–D and independent-G Mission workflow described in [Missions](../../docs/missions.md). This prototype remains an inert design reference; its simulated state and percentages are not execution evidence; production Pause/drain/Resume uses the real Engine and preserved checkpoints. See [verification](../../docs/verification.md) for actual source acceptance.
