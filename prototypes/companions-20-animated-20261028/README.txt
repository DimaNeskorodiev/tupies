TWENTY CUSHION COMPANIONS — HERMES STUDIO

Open index.html in a modern browser. No server, sign-in or installation is needed. All images, scripts and styles are local.

Each of the twenty main images is a real seven-frame transparent animated WebP. The native image loops through idle, blink, curious lean and wave. Pause animations swaps the displayed image to its still full-body PNG; it does not leave a hidden animated image running. Your system reduced-motion preference starts the gallery still. You can explicitly choose Play.

The Animation and Portrait PNG links download those images. The assets/ directory also contains still full-body PNGs. Production export files are copied byte for byte, without recoloring, alpha painting, filtering or re-encoding.

The sources/ directory preserves all twenty original four-pose PNG sheets and their exact ImageGen prompts. source-manifest.json records their hashes and paths. manifest.json records the production asset hashes, native frame timing and image paths. Original straight-alpha sources remain unchanged; actual RGBA compositing was verified on light and dark browser surfaces.

These loops are presentation animation, not a bot task status or a rigged 3D character.
